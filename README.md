# EcoTrend

EcoTrend é uma loja virtual fictícia com foco em produtos sustentáveis e ecológicos. O projeto foi desenvolvido como atividade acadêmica de Front-end, com foco em responsividade, organização visual e uso de componentes Bootstrap.

## Objetivo

Criar uma interface de e-commerce sustentável para apresentar produtos de diferentes categorias, como roupas, beleza, casa e tecnologia verde, com navegação intuitiva e experiência visual moderna.

## Funcionalidades

- Header com navegação e carrinho
- Carrossel de destaques na página inicial
- Cards de produtos com preços e botões de compra
- Página de categorias com filtros por categoria, marca e preço
- Página de detalhes do produto
- Página de contato com formulário
- Carrinho com total e botão de finalização
- Layout responsivo para desktop e mobile

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome
- Google Fonts
